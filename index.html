عن حياتي المهنية

الخلفية الأكاديمية

درست تقنية المعلومات وعلوم الحاسب بجامعة الملك عبدالعزيز، وصببت اهتمامي على التفاعل بين الإنسان والحاسوب (HCI) وعلم النفس الخصمي في الأمن السيبراني.

تصميم تجربة المستخدم

إبتكار أنظمة تصميم متكاملة (Design Systems) باستخدام Figma وCanva، وتحويل الأفكار المعقدة إلى نماذج تفاعلية واضحة وبسيطة.

التطوير والبرمجة

بناء واجهات برمجية متجاوبة وسريعة باستخدام HTML, CSS, JavaScript, React وتطبيقات Java المتقدمة المعتمدة على البرمجة كائنية التوجه والأمن.
