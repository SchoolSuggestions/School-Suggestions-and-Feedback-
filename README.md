# موقع الاقتراحات والشكاوى — المتوسطة التاسعة والستون + المتوسطة الثانية لتحفيظ القرآن

## خطوات التشغيل
1. أنشئي Google Sheet جديد > Extensions > Apps Script، والصقي `apps-script.gs`.
2. غيّري `ACCESS_KEY` و`ALERT_EMAIL` داخل الملف.
3. Deploy > New deployment > Web app (Execute as: Me، Who has access: Anyone) وانسخي الرابط.
4. ضعي الرابط مكان `ضعي_رابط_Apps_Script_هنا` في `index.html` و`dashboard.html`.
5. ارفعي الملفات إلى مستودع GitHub جديد وفعّلي GitHub Pages.

## الملفات
`index.html` (النموذج) · `dashboard.html` (لوحة الموجهة) · `style.css` (نفس ملف الغياب) · `theme.css` (الهوية البنفسجية) · `moe-logo.png` · `apps-script.gs`
