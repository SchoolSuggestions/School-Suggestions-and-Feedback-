# موقع البورتفوليو الشخصي الاحترافي 🚀

مرحباً بك! هذا المجلد يحتوي على كامل الأكواد والملفات التفاعلية لموقع شخصي بورتفوليو مخصص للرفع على **GitHub Pages**.

## 📁 هيكل الملفات
- `index.html`: الهيكل الأساسي للموقع باللغة العربية مع دعم السيو (SEO) والوصولية.
- `style.css`: التنسيقات والتصميم المتجاوب بأسلوب حديث مع وضع ليلي ونهاري.
- `script.js`: التفاعلية، التبديل بين الوضع المظلم والمضيء، تصفية المشاريع، ونماذج التواصل.

## 🛠️ طريقة رفع الموقع على GitHub ونشره مجاناً خلال دقيقتين:

1. **إنشاء مستودع (Repository) جديد:**
   - سجل دخولك إلى حسابك الجديد في GitHub.
   - انقر على **New Repository** (+ في أعلى اليسار).
   - اسمِ المستودع بأي اسم مثل `my-portfolio` (أو `username.github.io`).
   - اختر **Public** ثم انقر **Create repository**.

2. **رفع الملفات:**
   - في صفحة المستودع الجديد، اضغط على **uploading an existing file**.
   - قم بجر وإفلات الملفات الثلاثة (`index.html`, `style.css`, `script.js`) أو اخترها.
   - اضغط على **Commit changes**.

3. **تفعيل GitHub Pages (تشغيل الموقع):**
   - اذهب إلى **Settings** الخاصة بالمستودع.
   - من القائمة الجانبية اختر **Pages**.
   - تحت قسم **Build and deployment -> Branch**، اختر الفرع `main` (أو `master`) واجعل المجلد `/ (root)`.
   - اضغط **Save**.
   - انتظر دقيقة واحدة وستحصل على رابط موقعك المباشر مجاناً! 🎉
